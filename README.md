# LEVIRA

Last updated: 2026-11-16 09:40 AM EAT

Research & Consultancy — Public Health · WASH · Research & MEL · Policy

Mobile-first multi-page Next.js site with Unlumen UI, SmoothUI, and a first-party watermark-free atmosphere.

## Develop

```bash
./start.sh
# or
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router + React 19 + TypeScript + Tailwind CSS v4
- Free [Unlumen UI](https://ui.unlumen.com) primitives
- [SmoothUI](https://smoothui.dev) motion components
- First-party `AtmospherePlane` (CSS + Motion) — no Unicorn Studio

## Routes

| Path | Purpose |
|------|---------|
| `/` | Brand hero |
| `/about` | Background & experience |
| `/expertise` | WASH / public health domains |
| `/partners` | Clients & partners |
| `/contact` | Seed contact + inquiry UI |
